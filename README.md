## PROJECT SCOPE

The **Weather Aggregator Dashboard** is a dynamic web application that aggregates real-time weather metrics and
multi-day forecasts using asynchronous RESTful API calls.
Developed for Task 3 of the CodTech IT Solutions Software Development Internship, 
this application showcases modern JavaScript `async/await` patterns, dynamic geocoding integration, unit conversion state logic,
and browser `localStorage` persistence.

## Key Features

 **Global Search (Geocoding):** Allows users to search weather conditions for any global city using automated location name parsing.
 **Aggregated Weather Metrics:** Displays real-time temperature, relative humidity percentages, wind speed, and surface atmospheric pressure.
 **5-Day Weather Forecast:** Aggregates and renders daily maximum temperatures over a 5-day timeline.
 **Unit Conversion (°C / °F):** Seamlessly toggles measurement systems between metric (°C, km/h) and imperial (°F, mph).
 **State Persistence:** Remembers the user's last searched location and preferred temperature unit across page refreshes.
